# Portfólio Django — Django Admin

Instale Python 3.12 e as dependências com `python -m pip install -r requirements.txt`.
Execute `python manage.py migrate`, `python manage.py createsuperuser` (opcional para Admin) e `python manage.py runserver`.
Testes: `python -m pytest -q`.

Marco de entrega: branch `Django-Admin`, PR com base `codex/django-views`. O projeto é de desenvolvimento local; não usar a chave pública de desenvolvimento em produção.
